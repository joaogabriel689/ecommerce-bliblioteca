=========!IMPORTANTE========

	Por enquanto, vou salvar neste diretório as imagens dos nossos produtos, até que seja decidido um local mais adequado.

	--$pode ser alterado em futuras versões.

=========REGRAS==========
	1. A imagem deve ser salva com o nome do seu respectivo produto

	2. Espaços devem ser representados através de "_"

	3. No fim do nome, deve ser colocado um número que
	indique a ordem de cada fotografia, no caso dos anúncios
	que tenha mais de uma imagem. Ex: livro_legal_1.jpg, livro_legal_2.jpg...

	4. Se o produto tiver mais de um volume, este deve ser especificado. Ex: livro_maneiro_vol1_1.jpg, livro_maneiro_vol2_1.jpg...
